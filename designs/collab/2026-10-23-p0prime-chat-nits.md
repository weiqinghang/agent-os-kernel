# P0′ 聊天四条小修

冻结里记下、产品已同意下轮做的非阻塞项。只动聊天壳，不加内核阶段机，也不改 SSE / 取消 / DAS。

1. **依据按钮**：「查看第 N 条依据」只在该序号自己的依据条目（`- evidence:`，且前面没有连着的编号）存在时出现。样本列表 `1.`–`5.` 后面的指纹不再冒出「查看第5条依据」。
2. **时间窗确认**：点「确认」后，卡片收起的同时留下用户气泡「用近30天再出一版洞察报告」（随所选时间窗变化），不只剩卡片动作。占位符仍不会被当成用户消息。
3. **调试入口**：页眉「调试」默认不出现。地址栏 `?debug=1` 才露出开关；开关仍默认关，链路仍是白名单短句。
4. **收尾文案**：晚到的 `model_step` 映射成「正在整理结论」。认 `type` 为 `final` / `finalizing` / `loop_break`，或载荷里的 `finalizing` / `loop_break` 标记，或已不再要工具且 `n_calls` 为 0；`state=finalizing` 同样认。追加工具、`live_retry`、`live_fallback` 仍是「思考中」。不认 `phase_*`。工具名、mode、id 不上屏。
